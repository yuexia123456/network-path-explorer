# 后续路线图

按以下顺序推进：

1. IP 情报与质量证据：补充有来源、可解释、可复核的 provider 证据。住宅、静态、数据中心等质量绝不只根据地理位置推断。
2. Windows 网址诊断：在明确的系统权限和网络 API 边界内复用分层证据模型。
3. 应用选择与进程/socket 关联：先明确用户授权、数据最小化和跨平台限制，再关联应用、进程与连接。
4. 便携式发布加固：完善签名、升级、U 盘迁移、架构检查和离线启动体验。

每一阶段都必须保持这些边界：系统配置、TUN、Mihomo 决策/逻辑链、路由 hop、公网出口和测速路径分别标注；没有证据就显示未知或降级；公网服务不接收网址、控制器密钥、本地地址、规则或节点名称。
