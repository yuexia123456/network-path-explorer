# 第一次使用

## 我只想知道一个网站有没有走代理

启动 Network Path Explorer，在浏览器里输入网址，然后点击“检查网址”。
你可以直接输入域名，也可以粘贴 HTTP/HTTPS 链接。

先看中文结论，再按需查看路径和证据：

| 显示结果 | 通俗含义 | 不能由此得出的结论 |
|---|---|---|
| DIRECT / 直连 | Mihomo 没有为本次请求选择代理节点 | 不代表网站在国内，也不能排除透明代理 |
| PROXY / 经过代理 | Mihomo 为本次请求选择了代理路径 | 不代表浏览器的所有请求都走同一条路径 |
| REJECT / 被规则拦截 | 本次请求命中了拒绝规则 | 不代表网站自身故障 |
| UNKNOWN / 暂时无法确认 | 当前没有足够证据 | 不能当作直连，也不能当作一定走代理 |

系统代理配置只是线索。即使系统代理关闭，TUN 也可能接管请求。
TUN 接管后仍然可能选择直连，所以“经过 Clash”不一定“经过代理节点”。

## 我想看 IP

本机地址用于电脑和路由器之间通信。公网出口地址是单独一次 IP 查询看到的出口。
它可能与待检测网址走不同规则，因此界面会分别标注。

`127.0.0.1` 是电脑访问自己；`198.18.x.x` 等可能是代理工具生成的虚拟地址。
不能拿这些地址查国外落地位置。当前版本也不提供住宅/静态 IP 质量判断。

## 我想知道慢在哪里

网址检查显示这一次连接的状态和耗时，不读取网页正文。
登录后的网页还可能加载许多不同域名的图片、视频和接口。
所以一次连接快，不足以证明整个网页快。

网络跳点探测显示愿意回答的路由器；没有回答会保留为未知。
代理链图展示规则、策略组和节点，不是地理地图或互联网完整路线。
工具不能发现代理服务商没有公开的内部中转。

## 我想测速

测速需要主动开始，会消耗真实上传和下载流量。
快速模式上限 40 MB，完整模式上限 200 MB；可随时取消。
结果代表到 Cloudflare 的测试，不代表所有网站的速度。
网络协议开销和重传可能不包含在应用载荷预算内。

## 我想查一个应用整月用了多少流量

当前版本尚不支持应用选择和历史流量账本。
也不能恢复此前没有记录的历史。请查看[路线图](roadmap.md)。
